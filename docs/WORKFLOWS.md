# دورات العمل

## الشراء والاستلام

1. إنشاء مورد وشراء Draft مع الأصناف والتكلفة المتوقعة.
2. عند وصول جزء، إنشاء Receipt يحدد الكمية وBatch وتاريخ الصلاحية.
3. التحقق من الكميات، ثم Post transaction: زيادة المخزون، تسجيل التكلفة، وإضافة مديونية المورد.
4. تكرار الاستلام حتى الإغلاق؛ أي فرق أو إلغاء يمر بسياسة معلنة وسجل تدقيق.

## الطلب والبيع والتسليم

1. إنشاء طلب عميل واختيار الأصناف والكميات.
2. تحويله إلى فاتورة Draft؛ اقتراح FEFO لكل سطر ومراجعة المستخدم.
3. إدخال الخصم وBonus والمندوب وشروط الائتمان.
4. التحقق من المخزون والائتمان، ثم Post: خصم Batches، إنشاء StockMovements، وتثبيت snapshot الأسعار.
5. طباعة A4، تسجيل التسليم، ثم Payment عند التحصيل.

## التحصيل والحسابات

تسجيل Payment للطرف بالمبلغ وطريقة الدفع والمرجع، ثم تطبيقه وفق قاعدة يحددها العميل (أقدم فاتورة/اختيار يدوي/رصيد إجمالي). يعرض كشف الحساب الفواتير والمرتجعات والتحصيلات والرصيد الجاري.

## المرتجعات

المرتجع المرتبط يختار الفاتورة والسطور والكمية المتبقية للإرجاع، ويفحص حالة Batch والصلاحية، ثم Post يعيد المخزون ويخفض الحساب. المرتجع الاستثنائي يطلب سببًا ومرجع موافقة، وتبقى قواعده معلقة.

## الجرد والتسوية

تجميد/لقطة كمية اختيارية، إدخال العد الفعلي لكل Product/Batch، إظهار الفروق، طلب اعتماد، ثم إنشاء Adjustment وحركة تدقيق. لا يعدل الرصيد يدويًا خارج الحركة.

## الاستيراد والنسخ الاحتياطي

استيراد Excel: قالب معلن → معاينة → تحقق من الأكواد والتواريخ والأرصدة → تقرير أخطاء → تنفيذ transaction أو دفعات قابلة للاستئناف. النسخ الاحتياطي نسخة محلية مشفرة/محمية حسب القرار، واختبار استعادة دوري؛ الرفع السحابي اختياري عند توفر الإنترنت.

## معايير فشل مشتركة

أي فشل تحقق يمنع الترحيل دون تغيير جزئي، ويظهر سببًا قابلًا للتصحيح. كل Post أو Reverse يولد AuditEntry.
