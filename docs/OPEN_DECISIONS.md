# القرارات المفتوحة

هذه أسئلة تحتاج تأكيد العميل قبل تثبيت domain أو migration. لا يُفترض جوابها ضمن المتطلبات المؤكدة.

أضيفت متطلبات العميل المؤكدة في [CLIENT_REQUIREMENTS_SOURCE](CLIENT_REQUIREMENTS_SOURCE.md). الإجابات الواضحة هناك أزيلت من قائمة القرارات، أما البنود التالية فما زالت معلقة.

## التصنيف التشغيلي

- **Blocker:** يمنع تنفيذ وظيفة أو ترحيلها بأمان قبل الإجابة.
- **Non-blocker:** يمكن بناء الوظيفة مع إبقاء سياسة قابلة للتهيئة أو تأجيلها.
- **Recommended Default:** توجد سياسة افتراضية موصى بها، لكنها تحتاج موافقة قبل تطبيقها إذا أثرت ماليًا أو مخزنيًا.

| # | القرار | الخيارات/الأثر |
|---|---|---|
| 1 | **Blocker** — العملة والضرائب | هل توجد ضريبة/ضريبة قيمة مضافة؟ وهل الأسعار شاملة؟ يلزم قبل الحساب والطباعة. |
| 2 | **Recommended Default** — المخزون السالب | نوصي بالمنع؛ القرار يغير سلامة المخزون. |
| 3 | **Blocker** — الصلاحية | منع بيع المنتهي/الهامش/تجاوز FEFO؛ يلزم قبل ترحيل البيع. |
| 4 | **Blocker** — بونص البيع | البونص مؤكد وجوده؛ يلزم تحديد أثره على المخزون والتكلفة والهامش قبل البيع. |
| 5 | **Blocker** — الخصم | الخصم على سعر الجمهور ولا يوجد خصم إجمالي؛ يلزم تحديد النسبة/المبلغ والتقريب. |
| 6 | **Non-blocker** — التحصيل | يمكن بدء تسجيل التحصيل على الرصيد الإجمالي، لكن أسلوب التوزيع التفصيلي يؤثر على التقارير. |
| 7 | **Blocker** — المرتجع الاستثنائي | المرتجع دون أصل مقبول أحيانًا؛ يلزم مسار الاعتماد ومصير المخزون. |
| 8 | **Blocker** — الإلغاء والتعديل | التعديل المحفوظ مطلوب؛ يلزم تحديد هل يتم بعكس/إصدار نسخة وسجل تدقيق. |
| 9 | **Non-blocker** — أرقام المستندات | يمكن استخدام مولد مؤقت، لكن الصيغة النهائية مطلوبة قبل التشغيل الفعلي. |
| 10 | **Non-blocker** — الجرد | يمكن بناء جلسة جرد، وتحديد التجميد والاعتماد قبل الإنتاج. |
| 11 | **Non-blocker** — تنبيه النقص | يمكن تأجيل عتبة الحساب مع إبقاء الحركة والتقرير الأساسي. |
| 12 | **Blocker** — النسخ الاحتياطي | النسخ المحلي والخارجي مؤكدان؛ يلزم تحديد المسارات والحماية. cloud اختياري عند الإنترنت. |
| 13 | **Blocker** — الاستيراد | نطاق الاستيراد مؤكد دون الفواتير التاريخية؛ يلزم قالب Excel وسلوك التكرار والتاريخ. |
| 14 | **Non-blocker** — المستخدمون | مستخدم واحد يسمح ببدء الإصدار الأول؛ الصلاحيات مطلوبة قبل التوسع. |
| 15 | **Blocker** — التقريب | عدد المنازل وترتيب التقريب يؤثران في الفواتير والأرصدة. |

| 16 | **Blocker** — تجاوز المخزون | يلزم تحديد آلية الصلاحية الإدارية وحركة التسوية عند التجاوز؛ لا يُفترض رصيد سالب تلقائي. |
| 17 | **Blocker** — تكلفة المبيعات | يلزم اعتماد طريقة فصل التكلفة الفعلية عن سعر الشراء الحالي. |
| 18 | **Non-blocker** — مرتجعات الموردين | غير مطلوبة في المرحلة الأولى ويمكن تأجيلها. |

| 19 | **Blocker** — بيع المنتهي | خدمة FEFO الحالية ترتب المرشحين الذين يقدمهم المستهلك ولا تقرر سياسة بيع المنتهي؛ يلزم اعتماد المنع/الهامش قبل تطبيق التصفية. |
| 20 | **Blocker** — تسوية النقص | المجال يرفض الكميات غير الموجبة ولا ينشئ رصيدًا سالبًا؛ يلزم تحديد صاحب الصلاحية ومرجع StockOverride قبل تنفيذ التجاوز. |
| 21 | **Non-blocker** — تحديث هوية Batch | الهوية غير قابلة للتغيير في المجال؛ يلزم فقط تحديد مسار تصحيح إداري/عكس عند أخطاء الإدخال. |

## توصيات غير ملزمة

منع المخزون السالب، منع بيع المنتهي افتراضيًا، تطبيق التحصيل يدويًا مع اقتراح الأقدم، واستخدام decimal مع تقريب موحد. تصبح هذه متطلبات فقط بعد اعتمادها.
