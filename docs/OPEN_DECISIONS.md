# القرارات المفتوحة

هذه أسئلة تحتاج تأكيد العميل قبل تثبيت domain أو migration. لا يُفترض جوابها ضمن المتطلبات المؤكدة.

## التصنيف التشغيلي

- **Blocker:** يمنع تنفيذ وظيفة أو ترحيلها بأمان قبل الإجابة.
- **Non-blocker:** يمكن بناء الوظيفة مع إبقاء سياسة قابلة للتهيئة أو تأجيلها.
- **Recommended Default:** توجد سياسة افتراضية موصى بها، لكنها تحتاج موافقة قبل تطبيقها إذا أثرت ماليًا أو مخزنيًا.

## توصيات غير ملزمة

منع المخزون السالب، منع بيع المنتهي افتراضيًا، تطبيق التحصيل يدويًا مع اقتراح الأقدم، واستخدام decimal مع تقريب موحد. تصبح هذه متطلبات فقط بعد اعتمادها.
