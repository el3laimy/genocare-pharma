# GenoCare Windows x64 Manual Test Build

هذه حزمة اختبار يدوية وليست إصدار إنتاج. طريقة التوزيع الحالية **unpackaged self-contained**: لا توجد شهادة توقيع ولا MSIX installer، ويضم artifact ملفات التطبيق وWindows App SDK وSQLite native runtime.

## المتطلبات

- Windows 10 version 1809 (build 17763) أو أحدث، أو Windows 11.
- جهاز x64.
- قد يحتاج الجهاز Microsoft Visual C++ Redistributable x64 وفق مكونات Windows المثبتة؛ لا يحتاج .NET SDK أو قاعدة بيانات مثبتة.
- لا تشغّل الحزمة من مجلد مشترك غير موثوق، ولا تستخدمها مع بيانات إنتاجية.

## تنزيل وتشغيل

1. افتح GitHub Actions ثم workflow **Windows x64 test build**.
2. اختر **Run workflow** على الفرع المطلوب وانتظر نجاح جميع الخطوات.
3. افتح صفحة التشغيل الناجح ونزّل artifact باسم `GenoCare-win-x64-<commit-sha>`.
4. فك الضغط في مجلد اختبار محلي.
5. شغّل `GenoCare.Desktop.exe`. لا تنقل ملفات DLL خارج المجلد.
6. راجع `BUILD-METADATA.json` للتأكد من commit والمعمارية وطريقة النشر.

## قاعدة البيانات والاختبار الآمن

تُنشأ قاعدة SQLite في:

```text
%LOCALAPPDATA%\GenoCare\genocare.db
```

البرنامج يطبق migrations عند البدء، ولا يحتوي artifact على قاعدة بيانات مسبقة. لاختبار منفصل، استخدم حساب Windows أو جهاز اختبار منفصل، وانسخ مجلد `%LOCALAPPDATA%\GenoCare` احتياطيًا قبل التجارب. لإعادة ضبط **بيانات الاختبار فقط** أغلق البرنامج، أعد تسمية مجلد `GenoCare` إلى `GenoCare.test-backup-<date>`، ثم شغّل البرنامج لإنشاء قاعدة جديدة. لا تحذف مجلدًا قبل التأكد أنه ليس بيانات إنتاجية.

## جمع التشخيص

- سجّل commit من `BUILD-METADATA.json` ووقت الاختبار وإصدار Windows.
- صوّر رسالة الخطأ أو انسخ النص دون إرفاق قاعدة البيانات.
- لا تشارك `genocare.db` أو أي ملفات تحتوي بيانات العملاء؛ عند الحاجة شارك سجلًا منقحًا أو وصفًا للخطوات.
- سجّل Event Viewer فقط إذا طلب فريق التطوير ذلك، مع إزالة المسارات وأسماء العملاء.

- [ ] ظهور واجهة عربية RTL والتنقل بين الأصناف والتشغيلات.
- [ ] إنشاء صنف بكود واسم وأسعار صحيحة.
- [ ] البحث بالكود والاسم.
- [ ] تعديل الوصف والأسعار ثم الحفظ.
- [ ] حفظ الصنف نفسه مرتين دون إنشاء سجل مكرر.
- [ ] تفعيل وتعطيل الصنف.
- [ ] إنشاء Batch بتاريخ صلاحية صحيح.
- [ ] رفض Batch مكرر للصنف نفسه برسالة مفهومة.
- [ ] التبديل السريع بين أصناف والتحقق من عدم بقاء تشغيلات الصنف السابق.
- [ ] عرض أرصدة Available وQuarantined وDamaged للقراءة فقط.
- [ ] إغلاق التطبيق وإعادة فتحه.
- [ ] التحقق من بقاء الأصناف والتشغيلات بعد إعادة الفتح.
- [ ] إدخال قيم غير صحيحة والتحقق من رسائل عربية وعدم حفظ بيانات جزئية.
- [ ] اختبار فشل تهيئة قاعدة البيانات في بيئة اختبار فقط والتحقق من ظهور شاشة الخطأ العربية.

## حدود الاختبار

هذه الحزمة لا تشمل المبيعات أو المشتريات أو الحسابات أو override إداري. نجاح بناء ونشر WinUI لا يثبت وحده أن التشغيل الرسومي يعمل على كل جهاز؛ يجب تنفيذ القائمة يدويًا على Windows x64.
